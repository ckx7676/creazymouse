# 疯狂的老鼠 \- 自动点击器

## 📌 项目介绍

**疯狂的老鼠（creazymouse）** 是一款基于 Python \+ Tkinter 开发的**带随机偏移、防检测、可自定义快捷键**的Windows自动点击工具。

专为长时间重复点击、游戏挂机、自动化操作场景设计，区别于普通连点器，内置**高斯随机坐标偏移、随机点击间隔**，最大程度规避风控检测，运行稳定、无卡顿、免常驻后台冗余进程。

### ✨ 核心功能

- **多动作支持**：鼠标左键、右键、滚轮上滚、滚轮下滚

- **三档点击速率**：高速模式、慢速模式、自定义间隔参数

- **防检测机制**：高斯分布随机坐标偏移、随机点击浮动间隔

- **全局快捷键控制**：支持自定义启动/停止全局热键，无需点击窗口

- **权限自启**：程序自动申请管理员权限，适配所有需要权限的操作场景

- **可视化GUI界面**：简洁直观，参数可实时调整、状态实时显示

- **配置持久化**：快捷键配置自动保存，重启程序不重置

- **窗口图标美化**：自定义程序窗口、子窗口、EXE图标

## 💻 运行环境

- 系统：**仅 Windows 系统**（依赖 Windows 专属组件）

- Python 版本：Python 3\.8 及以上（推荐 3\.10/3\.11）

- 打包工具：Nuitka（高性能Python打包工具，优于PyInstaller）

## 📦 依赖安装

### 1\. 依赖清单（requirements\.txt）

项目仅需两个第三方库，其余均为Python内置模块

```txt
pynput
keyboard
```

### 2\. 一键安装依赖

在项目根目录打开终端，执行：

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install pynput keyboard
```

## 🚀 运行方式

### 方式一：源码直接运行

安装依赖后，直接运行主程序：

```bash
python creazymouse.py
```

程序会**自动申请管理员权限**，允许后即可打开GUI界面使用。

### 方式二：编译为EXE程序（推荐）

使用pip安装Nuitka编译工具：

```bash
pip install Nuitka
```

项目内置 `build.bat` 一键Nuitka打包脚本，无需复杂命令，开箱即用。

#### 打包特性（已全部配置完成）：

- 纯64位编译、LTO性能优化，运行速度更快

- 无控制台黑窗口，纯GUI运行

- 内置ICO图标，EXE文件\+窗口双图标生效

- 默认管理员权限运行

- 自动清理旧打包文件，输出至dist目录

- 适配Tkinter窗口插件，不会闪退报错

#### 打包步骤：

1. 确保项目根目录存在：`creazymouse.py`、`creazymouse.ico`、`build.bat`

2. 双击运行 **build\.bat**

3. 等待编译完成，EXE程序输出在 `dist` 文件夹内

## 📖 使用教程

### 1\. 默认快捷键

- 启动自动操作：`Alt + 1`

- 停止自动操作：`Alt + 2`

### 2\. 自定义快捷键

1. 点击界面左上角 **⚙ 快捷键设置**

2. 点击对应「修改」按钮，按下新的快捷键组合

3. 按 Enter 确认、ESC 取消

4. 点击保存，程序自动重启生效

### 3\. 参数设置说明

- **点击/滚动动作**：选择需要执行的操作（左键/右键/上下滚轮）

- **点击档位**：高速、慢速、自定义三档可选，自定义可自由调节间隔

- **点击间隔参数**：设置基础点击间隔 \+ 随机浮动范围

- **坐标随机偏移**：开启后模拟人手微操，防止系统/平台检测

## ⚠️ 重要注意事项

- **必须管理员权限**：程序自动请求权限，请勿拒绝，否则热键、鼠标操控可能失效

- **仅支持Windows**：依赖Windows专属API，不支持Mac/Linux

- **杀毒软件误报**：自动化工具易被误报病毒，打包后可添加信任/白名单

- **文件完整性**：打包时确保 `creazymouse.ico` 图标文件在根目录，否则无图标

- 运行中界面会锁定参数，停止后可重新修改配置
